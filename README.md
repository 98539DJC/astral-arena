# 星序竞技场 · Astral Arena VII

十六名角色、每方三人的独立回合制联机课程项目。角色包括姬子、杰帕德、藿藿、景元、布洛妮娅、卡芙卡、彦卿、艾丝妲、三月七、丹恒、希儿、娜塔莎、克拉拉、银狼、阮·梅和流萤，使用官方展示素材与课程版改编机制。角色图鉴、编队、抽卡、账号头像与战斗画面同步更新。官方素材署名见 ASSET_CREDITS.md；具体机制与课程版调整见 CHARACTER_MECHANICS.md。

保留注册登录、昵称头像、密码修改、恢复码找回、登录设备管理、跨设备存档和管理员控制台。支持单抽/十连、保底、定向保证、重复转星尘、指定兑换、任务与对战奖励。抽卡不涉及付费，重复角色不增加战斗属性。

## 星灯纪行与新手引导

新增原创四章八关剧情。每关提供固定试用小队，无需先抽齐角色；首通依次可获得三月七、丹恒、娜塔莎与希儿。剧情进度随账号保存，奖励由服务器重放战斗后发放，每关仅领取一次。首次进入大厅提供启航指引，第一关逐步高亮选目标、普攻、终结技和战技；可跳过，也可从剧情页重看。

新增三月七、丹恒、希儿、娜塔莎、克拉拉、银狼、阮·梅和流萤，加入抽卡、星尘兑换、头像和联机编队。银狼按原版单体机制适配，阮·梅与流萤按课程版简化。旧角色内部标识与原收藏保持。

## 试玩

首次注册拥有姬子、杰帕德、藿藿，以及 3,200 星石。点击「星海跃迁」招募，点击「编队出战」开始人机演练，或「联机对战」创建房间，把房间号给另一位玩家。双方登录各自账号、选择三名角色并准备后开始。

- 点敌人选择攻击目标，点队友选择治疗/拉条目标，点角色名字看技能；按 1 普攻、2 战技、3 防御。
- 每队共享最多 5 战技点；匹配弱点削韧，击破追加伤害并延后行动。
- 满 100 能量可施放终结技，不占普通行动。神君与追击自动结算。
- 推荐阵容：击破守护、神君连奏、持续引爆、巡猎加速。
- 角色状态栏显示剩余回合，机制栏显示蓄能、神君段数、禳命、智剑连心等。

## 本地启动

需要 Node.js 24 或更新版本，无第三方依赖。可在 GitHub 点击 Code → Download ZIP 并解压，或使用 Git：

~~~powershell
git clone https://github.com/98539DJC/astral-arena.git
cd astral-arena
~~~

在项目目录运行：

~~~powershell
node scripts/build.mjs
node scripts/serve.mjs
~~~

Windows 安装好 Node.js 后，也可双击「启动游戏.cmd」。浏览器访问 http://localhost:4173。局域网手机使用电脑的局域网 IP 与 4173 端口，双方需能互访。异地联机需运行游戏服务器，并通过自有服务器或内网穿透提供可访问的地址；把源码传到 GitHub 后仍需另行运行游戏服务。

本地数据保存在 .openai/preview.sqlite，线上由 D1 保存。Cookie 会话绑定游戏账号，同一服务器可跨设备继续角色与保底进度。房间有效期 6 小时，普通回合超时 45 秒自动防御；同一标签页刷新会尝试恢复房间。升级后保留账号与收藏，重新创建房间即可，旧人机领奖记录不继续执行。离线 HTML 单独使用浏览器存档。

公开仓库包含源码、数据库结构、角色资源来源与测试；不含现有玩家数据库、管理员账号、密码、访问令牌或原部署配置。首次启动会创建空数据库，需自行注册账号。`.openai/hosting.json` 为可选的原托管配置，本地构建与运行不需要该文件。

如需管理员，在游戏中注册自己的账号后，对本地源码版执行以下命令，再重新登录（将 `your_account` 替换为已注册账号）：

~~~powershell
$env:ARENA_DATABASE = ".openai/preview.sqlite"
node scripts/set-admin.mjs your_account
~~~

## 主要文件

| 文件 | 内容 |
| --- | --- |
| src/campaign.js、src/client-story.js | 四章八关、账号首通奖励、剧情对话与实战引导 |
| src/engine.js | 十六名角色、神君、行动条、状态、确定性随机数和战斗结算 |
| src/collection.js | 招募、保底、任务与奖励 |
| src/client.js、src/client-account.js | 对战、账号、大厅和角色档案 |
| src/characters.css | 官方立绘构图、头像与机制提示 |
| src/art/ | 48 张 WebP 角色资源、来源清单和原创观测站背景 |
| worker/index.js、worker/accounts.js、worker/admin.js | 房间裁决、账号、管理和奖励复算 |
| drizzle/ | 幂等数据库升级 |
| scripts/build.mjs | 嵌入全部图片与界面的独立 Worker |

运行时不向素材站请求图片。立绘 PNG 原件保留在上级素材目录；旧 CC0 素材归档到 design/legacy-art。官方图片与旧 CC0 授权分开记录。
